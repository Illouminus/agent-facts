# W8 · Ops on illouminus + digest + state — Implementation Plan · 2026-10-20

> **For agentic workers:** executed inline by the W8 session (executing-plans); steps use `- [ ]`.

**Goal:** the registry runs on illouminus by itself — API behind Caddy, probes every 15 min, a
Monday digest into megabrain state (+ a Telegram ping), deploy on merge with health check and
rollback, a journal line per deploy, kill switch tested on the host.

**Architecture:** no Docker. A git checkout of the repo at `~/apps/agent-facts` (detached at the
deployed sha), `uv sync --frozen --no-dev` into its `.venv`, transient data in `var/` (gitignored).
systemd **user** units live in `ops/systemd/` and are `systemctl --user link`ed from the checkout.
GitHub Actions only ssh-es a 40-hex sha to a forced command that runs `ops/deploy.sh`; the host
fetches, checks the sha is on `origin/main`, checks it out, syncs, restarts, polls `/healthz`, rolls
back on failure. Deterministic scripts only: no LLM anywhere in ops.

**Tech stack:** bash (deploy, must also run under macOS bash 3.2 for the local tests), Python 3.12
stdlib + the `apifacts` package (digest, journal hook), pytest, systemd user units, Caddy.

**Spec:** `docs/specs/08-ops-autonomy.md`, `09` (W8 + Process), `00` (layout, invariants), `03`/`05`
(what observations.sqlite holds), `04` (results.jsonl, kill switch).

## Decisions taken here (deviations and choices, listed again in the PR body)

| Topic | Choice | Why |
|-------|--------|-----|
| Deploy shape | git checkout + `uv sync`, not a GHCR image | one Python process, no build step; the 11 GB box keeps its disk; spec 00 gets one line |
| API port | `127.0.0.1:8795` | free on illouminus (8787/8788/8790 taken) |
| Data | `~/apps/agent-facts/var/` — `results.jsonl`, `probe-state.sqlite`, `observations.sqlite`, `deploy/` | `var/` is already gitignored; one place to back up or wipe |
| Probe edits to `facts/` | deploy carries the uncommitted `facts/` diff across a checkout (`git diff` → patch → `git apply`), parks it in `var/deploy/` when it no longer applies | the runner rewrites evidence in place; until the W4 bot publishes it, a deploy must not wipe it nor conflict on it |
| Units | linked from the checkout; deploy runs `daemon-reload` only when `ops/systemd/` changed | units stay reviewed in git; enabling stays a deliberate act |
| Quorum timer | written, **not enabled**, comment in both files | W4 not merged; `apifacts quorum` does not exist yet |
| Digest window | the last complete salt period: Monday 00:00 UTC −7 d → Monday 00:00 UTC; `--current` = the running period up to now (for test runs) | equals the reporter-net salt period (D-085): "networks" is then an exact distinct count |
| Digest language | report and ping in Russian, metric names as in spec 08 | portfolio rule: reports in `state/reviews` are Russian |
| Telegram | `send_telegram` through the local gateway (`127.0.0.1:8787/mcp`, header `X-Routine: agent-facts-digest`, `class: digest`) | the gateway is the only sanctioned path; today it diverts a digest that is not from `pm-weekly` — patch as an infra card, not a bypass |
| Publish button | none until `ops/publish-policy.yaml` has `approved: true`; the digest prints `publications: policy not approved yet, N candidates` | spec 08 + 09: the policy is Edouard's tap |

### Task 3 — `ops/digest.py` (TDD)

Pure functions, one I/O shell:

```python
@dataclass(frozen=True)
class Window: start: datetime; end: datetime; complete: bool   # UTC, end exclusive
def salt_window(now: datetime, current: bool) -> Window
def fact_metrics(facts, window) -> FactMetrics          # by status, +created in window, needs_probe
def probe_metrics(results_path, services, window) -> ProbeMetrics   # runs, outcomes, skipped keys, budget gaps
def check_metrics(db_path, window) -> CheckMetrics      # counters + distinct reporter_net
def publication_candidates(policy, facts) -> tuple[int, bool]   # (n, approved)
def render_report(d: Digest) -> str                     # markdown, starts with "# "
def render_ping(d: Digest, url: str) -> str             # 5–8 lines
def needs_probe_card(d: Digest, today) -> tuple[str, str] | None   # (task id, markdown)
def send_digest(text, endpoint, routine) -> SendResult  # JSON-RPC tools/call send_telegram
```

- [ ] Tests (fixtures only, no network except a local `HTTPServer` for the gateway client):
  window on a Monday 06:00 UTC and on a Tuesday (`complete` and `--current`); facts by status and
  `+N` by `provenance.created`; `needs a probe` = `reported` without `evidence.probe`; probe runs
  counted inside the window only, `skipped:no_key` → key names, budget gap = two http steps of one
  `(service, method, template, vantage)` closer than `probe_budget.per_template_seconds`;
  counters: total `unregistered_target` (not the sum with `:host` rows), top hosts without `other`,
  `dropped_*`, `stored`, distinct nets; missing sqlite/results → zeros and a "нет файла" note, not a
  crash; policy `approved: false` → `публикации: политика не утверждена, кандидатов N` and no
  button; ping ≤ 8 lines with the reports URL; report deterministic (same input → same bytes);
  card text passes the state contract (frontmatter keys, `## Что / ## Почему / ## Что сделать /
  ## Готово когда`); gateway client: sends header `X-Routine`, `class: digest`, reads `sent`/
  `diverted` from the tool result; `--dry-run` writes nothing and calls nothing.
- [ ] Implement. `uv run pytest tests/ops -q`, `uv run ruff check .`. Commit.
