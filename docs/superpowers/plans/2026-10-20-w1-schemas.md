# W1 · Schemas + validator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** JSON Schema 2020-12 files for fact, service, probe, observation and fix (spec 01, 02), pydantic
mirrors other packages import, a validator CLI `agentfacts validate [paths]` with `file:line: code message`
output and exit codes 0/1/2, and `agentfacts render-fix <json>` rendering any fix to one English sentence.

**Architecture:** The JSON Schemas in `schema/` are the gate (CI, contributors); `agentfacts/schema/models.py`
mirrors them for W2–W6 code and parity tests keep the two in step. YAML is loaded with ruamel round-trip
(timestamps kept as strings, line numbers kept). Validation runs in two passes: per-document JSON Schema
(error codes come from `x-error-codes` annotations in the schemas, else a location fallback), then
cross-document checks through a `Registry` (services, templates, probes) that W2/W3 can reuse.

**Tech Stack:** Python 3.12, jsonschema 4.26 (Draft 2020-12 + `referencing`), pydantic 2.14, ruamel.yaml
0.19, typer, pytest.

**Spec:** `docs/specs/01-fact-schema.md`, `docs/specs/02-fix-vocabulary.md`, `docs/specs/09-work-breakdown.md` § W1.

## File map

| File | Responsibility |
|------|----------------|
| `schema/fix.schema.json` | discriminated union on `action` (16 branches, `if`/`then` per action so errors point at the parameter) |
| `schema/fact.schema.json` | fact record; `$ref`s `fix.schema.json`; status rules as `if`/`then` |
| `schema/service.schema.json` | service registration (hosts, templates, signal_fields, dimensions, auth, tos, budget ≥ 300 s) |
| `schema/probe.schema.json` | declarative probe; prod ⇒ every http step is `GET`/`HEAD` |
| `schema/observation.schema.json` | one observation row (no bodies, headers, raw IPs) |
| `agentfacts/schema/__init__.py` | `load_schema(name)`, `schema_registry()` (repo `schema/` or packaged copy) |
| `agentfacts/schema/yamlio.py` | `load_yaml(path)` → ruamel data with line info, timestamps as `str`; `line_of(doc, path)` |
| `agentfacts/schema/models.py` | pydantic mirrors: enums, 16 fix models + `Fix` union, `Fact`, `Service`, `Probe`, `Observation` |
| `agentfacts/schema/registry.py` | `Registry` of services/probes, `match_template(path, template)` |
| `agentfacts/schema/validate.py` | `Problem`, `validate_paths(paths, root)`, codes, cross-document checks |
| `agentfacts/fixes/__init__.py`, `agentfacts/fixes/templates.py` | `render_fix(fix) -> str`, one renderer per action |
| `agentfacts/cli.py` | `validate`, `render-fix` commands (thin) |
| `tests/fixtures/valid/{service-stripe,fact-idempotency-key-reuse,probe-idempotency-key-reuse}.yaml` | spec 01 examples |
| `tests/fixtures/invalid/*.yaml` | the five rejection cases |
| `tests/schema/test_fixtures.py`, `test_cross_checks.py`, `test_models.py`, `test_validate_cli.py` | validator and mirrors |
| `tests/fixes/test_fix_schema.py`, `test_templates.py` | union rules, golden sentence per action, `render-fix` CLI |

## Error codes (stable; tests assert them)

| Code | Raised when |
|------|-------------|
| `yaml_error` | file does not parse as one YAML document |
| `not_a_mapping` / `unknown_document` | top level is not a mapping / is neither service (`key`), probe (`steps`) nor fact (`claim`/`kind`) |
| `claim_too_long` | `claim` > 300 chars |
| `error_string_too_long` | `signal.error_string` or `signal.normalized` > 512 chars |
| `unknown_kind` | `kind` not in the 01 enum |
| `fix_invalid` | any schema error inside a `fixes[]` entry (free text, extra field, bad parameter) |
| `unknown_fix_action` | `action` not in the 02 table |
| `no_fix` / `too_many_fixes` | 0 or > 3 fixes |
| `status_env_mismatch` | `verified:server:<env>` with `dimensions.env` ≠ `<env>` |
| `verified_needs_probe` / `official_needs_url` | status needs `evidence.probe` / `evidence.official_url` |
| `prod_probe_not_readonly` | probe with `env: prod` has a non-`GET`/`HEAD` http step |
| `tos_not_allowed` | service `tos` does not allow automated access or publishing |
| `budget_too_low` | `probe_budget.per_template_seconds` < 300 (invariant 6) |
| `schema_<keyword>` | any other JSON Schema failure (e.g. `schema_required`) |
| `duplicate_id`, `id_mismatch` | two inputs share an id / id disagrees with `service` or file location |
| `unknown_service`, `unknown_probe` | reference to a service / probe that is not loaded |
| `unregistered_template` | fact target, `use_endpoint` fix or probe step path matches no registered `(method, path)` |
| `foreign_url` | a URL inside a fix whose host is not the vendor's |
| `unknown_account_state` | `account_state` not `any` and not listed by the service |

Context: `validate_paths(paths, root)` also loads `root/services/` and `root/probes/` as context (errors in
context-only files are not reported; inputs shadow context documents with the same id).
