# W0 · Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A uv-managed Python 3.12 package `apifacts` with a typer CLI (`apifacts version`), one cheap CI job (ruff + pytest), and the public-facing repo files (English README, CONTRIBUTING, CODEOWNERS, .editorconfig).

**Architecture:** Single package `apifacts/` at the repo root (no `src/` layout, matching `00-architecture.md`). Version lives once in `apifacts/__init__.py` and is read by hatchling (`dynamic = ["version"]`). The CLI is one typer app in `apifacts/cli.py` with a root callback so later packages (W1 `validate`, W2 `probe`, W6 `check`) add subcommands without restructuring. CI is one job on `ubuntu-latest` with uv cache; nothing else runs, to stay under 2 minutes of paid minutes.

**Tech Stack:** Python 3.12, uv 0.13, hatchling, typer, pytest, ruff, GitHub Actions (`astral-sh/setup-uv`).

**Spec:** `docs/specs/09-work-breakdown.md` § W0, `docs/specs/00-architecture.md` (layout, stack), `docs/specs/03-check-contract.md` (curl example).

## File map

| File | Responsibility |
|------|----------------|
| `pyproject.toml` | package metadata, runtime deps, dev group, ruff + pytest config, console script |
| `.python-version` | pins the interpreter uv uses locally and in CI (`3.12`) |
| `uv.lock` | locked resolution, CI installs with `--locked` |
| `apifacts/__init__.py` | `__version__` (single source of truth) |
| `apifacts/cli.py` | typer `app`, root callback, `version` command |
| `tests/test_cli.py` | CLI behaviour through `typer.testing.CliRunner` |
| `.github/workflows/ci.yml` | one job: `uv sync --locked`, `ruff check`, `pytest`; slot for `apifacts validate` (W1) |
| `README.en.md` | public English description, ≤ 400 words, one curl `POST /v0/check` |
| `CONTRIBUTING.md` | dev setup, contribution ladder, fact-PR rules, licenses |
| `.github/CODEOWNERS` | `/facts/ @Illouminus` |
| `.editorconfig` | utf-8, LF, final newline, indent per file type |

Ruff rule set is deliberately small (`E,F,W,I,UP,B`, `B008` ignored for typer/FastAPI defaults) and CI runs
`ruff check` only, not `ruff format --check`: the parallel W2–W6 sessions are told to run exactly
`ruff check` and `pytest` before pushing, and a stricter CI would cost them extra paid runs.

- [ ] **Step 1: Write the failing test**

```python
from typer.testing import CliRunner

from apifacts import __version__
from apifacts.cli import app

runner = CliRunner()


def test_version_prints_package_version():
    result = runner.invoke(app, ["version"])
    assert result.exit_code == 0
    assert result.stdout.strip() == __version__


def test_help_lists_version_command():
    result = runner.invoke(app, ["--help"])
    assert result.exit_code == 0
    assert "version" in result.stdout


def test_no_command_is_a_usage_error():
    result = runner.invoke(app, [])
    assert result.exit_code == 2
```

- [ ] **Step 2: Run test to verify it fails**

Run: `uv run pytest -q tests/test_cli.py`
Expected: FAIL — `ModuleNotFoundError: No module named 'apifacts.cli'`.

- [ ] **Step 3: Write minimal implementation**

```python
"""Command-line entry point: `apifacts <command>`."""

import typer

from apifacts import __version__

app = typer.Typer(
    help="agent-facts: verified facts about machine interfaces for AI agents.",
    no_args_is_help=True,
    add_completion=False,
)


@app.callback()
def main() -> None:
    """Root callback: keeps `version` a subcommand while it is the only one."""


@app.command()
def version() -> None:
    """Print the apifacts version."""
    typer.echo(__version__)
```

Note: with `no_args_is_help=True` typer prints help and exits with code 2 in recent versions; if the
installed typer exits 0 instead, adjust the third test to the observed contract **only after** checking
that `apifacts` with no args is treated as usage (W1 needs exit 2 for usage errors).

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

  group: ci-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read

jobs:
  check:
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@v7
      - uses: astral-sh/setup-uv@v10.3.0  # no floating major tag upstream

          enable-cache: true
      - run: uv sync --locked
      - run: uv run ruff check .
```
