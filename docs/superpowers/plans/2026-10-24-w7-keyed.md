# W7 · Seed content, wave 1 — keyed services · 2026-10-24 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans (inline, one session). Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** two new probe auth kinds (`path_prefix`, `google_service_account`) in the runner, then six
keyed services seeded with ≥ 10 facts each (stripe, gemini, telegram, google-sheets, google-calendar,
google-firestore), one PR each.

**Architecture:** auth stays declarative in `services/<s>.yaml::auth`; the runner alone turns a key
file into credentials. `path_prefix` glues the key into a path prefix the registered templates never
contain (`/bot{key}` + `/getMe`); `google_service_account` signs an RS256 JWT with the service-account
JSON key and trades it at `https://oauth2.googleapis.com/token` for a short-lived access token, sent
as `Bearer`. Every secret form (raw key, JSON key, PEM, `private_key_id`, minted access token) joins
the run's `Redactor` before anything is written.

**Tech Stack:** Python 3.12, pydantic 2, httpx, `cryptography` (new dependency, RS256 signing only),
pytest + pytest-httpserver, ruff, uv.

Specs: `docs/specs/09-work-breakdown.md` (W7, Process), `01`, `02`, `04`. Branches from a fresh
`origin/main` in the worktree `/Users/edouard/dev/agent-facts-w7k`: `feat/runner-auth-kinds`, then
`content/w7-wave1-<service>`. Specs and `docs/decisions.md` are not touched.

## Per service (one PR each, in order)

1. Smoke by hand (one or two requests, no output of key values): the endpoint answers with the key.
2. `services/<s>.yaml`: hosts, ≤ 20 templates, `signal_fields`, `dimensions` (env, account_state),
   `auth` with the key name, ToS source, `probe_budget`.
3. `probes/<s>/*.yaml` (≥ 5); prod probes read-only (GET/HEAD); Stripe sandbox probes may create
   objects. A fragile assertion (schema fingerprint) gets its own probe.
4. `facts/<s>/*.yaml` (≥ 10): `verified:server:<env>` only when a probe asserts the signal, else
   `official` with the vendor doc URL; `signal.normalized` via `agentfacts.api.normalize.normalize`;
   `confirmations: 0` until the run; no `reported`; claims ≤ 300 chars, no advice; fixes from `02`.
5. Scratch root with only this service → `uv run agentfacts probe run --all --vantage mac-dev
   --root <scratch>`; copy facts back; `first_seen` = first `last_confirmed`.
6. Secret check: `grep -E 'sk_test_|AIza|<telegram numeric prefix>|BEGIN PRIVATE KEY|ya29\.'` over
   results.jsonl and the run log → empty (the prefix itself is never printed: grep `-c`).
7. `uv run agentfacts validate && uv run agentfacts pages build && uv run ruff check . && uv run pytest -q`
   → PR ready with the run log → `/code-review` → fix → CI → squash merge.
