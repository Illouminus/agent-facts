# W5 · Pages generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apifacts pages build [--root .] [--out pages/] [--check] [--registry-version DATE]` turns
`services/` + `facts/` into static markdown pages (spec 06): one page per fact titled with the exact
normalized error string, one index per service, a root index, and `errors/<hash12>.md` search-bait stubs.
Same input → byte-identical output; `--check` exits 1 when `pages/` is not what the registry generates.

**Architecture:** `build.py` loads and validates documents through the W1 pydantic models, decides what
is published (expired `reported` facts are not) and returns `{relative path: text}`; it also owns the
write/check step against an output directory. `templates.py` is pure rendering (one function per page
type plus markdown-safety helpers). `errors_index.py` groups published facts by `sha256(normalized)` for
the stubs. Fix sentences come only from `apifacts.fixes.templates.render_fix`. No clock, no git: every
date on a page comes from the YAML.

**Tech Stack:** Python 3.12, pydantic 2 (W1 models), ruamel (W1 `load_yaml`), typer, pytest.

**Spec:** `docs/specs/06-pages.md`, `docs/specs/01-fact-schema.md` (status rules), `docs/specs/02-fix-vocabulary.md`,
`docs/specs/03-check-contract.md` (request shape, hash = sha256 of normalized), `docs/specs/09-work-breakdown.md` § W5.

## Decisions (each goes into the PR's "Assumptions that might be wrong")

1. **Registry version = latest date in the data** (max of `evidence.first_seen`, `evidence.last_confirmed`,
   `provenance.created`, `provenance.history[].date`, as UTC dates), overridable by `--registry-version`.
   Not the git commit date: a squash merge gives main a new commit date, so `--check` on main would fail
   after every merge across midnight, and every code-only commit would make pages stale.
2. **Expired `reported`** (01: 30 days without quorum refresh) is measured against the registry version,
   not the clock: freshness = max(first_seen, last_confirmed); older than 30 days → no page, no index row,
   no stub. Kept in git.
3. **Badges:** ✅ any `verified:*`, 🟡 `reported`, ⚪ `stale`, ⛔ `retracted`, and 🔵 `official` (06 gives no
   badge for official).
4. **Retraction reason:** the schema has no reason field; the reason is the suffix of the latest
   `provenance.history[].change` of the form `retracted:<reason>` (`_`/`-` read as spaces). Missing →
   "reason not recorded".
5. **H1:** `signal.normalized` in a code span when present (whitespace runs shown as one space so the
   heading stays one line), else the claim as escaped text. Raw `error_string` never appears on a page.
6. **Observations:** published only at k ≥ 3 (invariant 7): 0 → "none from reporters yet", 1–2 →
   "fewer than 3 reporter networks", ≥ 3 → the number.
7. **Links** assume `pages/` sits at the repository root (`../../probes/...`, `../../facts/...`), whatever
   `--out` is, so output does not depend on the output path.
8. **Removal is marker-based:** `build` deletes, and `--check` reports, only `.md` files under `--out` that
   carry the generated-page footer; hand-written files in `pages/` are left alone.
9. **Fixtures in CI:** the golden test runs the real CLI (`pages build --root <fixture tree> --out
   tests/pages/golden --check`) inside `pytest`; the CI step `pages build --check` covers the real
   registry. Golden input is an explicit fixture list, so fixtures other packages add to
   `tests/fixtures/valid/` do not break W5 goldens. Regenerate: `UPDATE_GOLDEN=1 uv run pytest tests/pages -q`.
10. **Collisions are errors:** fact slug `index`, service key `errors`, or two different normalized strings
    sharing a 12-hex prefix stop the build with exit 1.

## Page shapes

Fact page (spec 06 template; sections omitted when the data is absent):

```
# `<normalized>`                     (or: # <claim>)

**<Service> · <METHOD> <path_template> · SDK `<pkg>` (<eco>) `<versions>` · HTTP <status> `<code>`**

Status: <badge> <status> · first seen YYYY-MM-DD · last confirmed YYYY-MM-DD · N confirmations from M vantages[ · not yet reproduced by a probe | · not reproduced by the last N probe runs; not refuted]

> <claim>

## What to do
1. <render_fix sentence>.

## Dimensions
env: prod · plan: any · region: any · account_state: any · also seen: [sandbox](<sibling>.md) (verified YYYY-MM-DD)

## Evidence
Probe `<id>` (declarative, [source](../../probes/<s>/<slug>.yaml)) · official doc: <https://…>

Observations: …

## Machine access
```sh
curl -s https://facts.baillot.dev/v0/check -H 'content-type: application/json' -d '<json>'
```
YAML: [facts/<s>/<slug>.yaml](../../facts/<s>/<slug>.yaml)

---

Data: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · agent-facts registry · This page is generated; edit the YAML, not the page.
```

Siblings ("also seen") = other non-retracted facts of the same service with identical `kind`, `target`
and `signal` but different `dimensions`. Retracted page = H1 + one status line with date and reason + footer.
