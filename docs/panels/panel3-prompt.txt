THE PROJECT: "a verified changelog of reality for AI agents" — an open, public dataset of typed FACTS about what third-party machine interfaces (HTTP APIs, SDK packages, CLIs) ACTUALLY do today, as opposed to what their docs say. Examples of facts: "stripe-python 21.1 dropped field X from 404 responses", "Apollo search returns HTTP 200 with an empty array instead of 429 when daily credits are exhausted", "Etherscan rate-limits with HTTP 200 and body status:0", "Slack chat.postMessage returns a generic 400 when blocks has more than 50 elements", "GitHub Actions API started requiring scope Y on 2026-10-14". Each fact is a small typed YAML file: service, endpoint or package+version, kind (status behavior, required header, schema variant, rate-limit behavior, breaking change), first-seen date, source URL, and a REPRODUCTION (an HTTP request with an assertion, or a sandbox script "install package@version, run check, expect exit 0"). Uptime/health of APIs is just one fact kind, a by-product, not the product.
How it works: the dataset lives in a public GitHub repository. Anyone, including autonomous agents, contributes by opening a pull request in the strict schema. CI (GitHub Actions plus the project's own probe servers on 3 vantage points) RE-EXECUTES the reproduction; a merge bot merges only what passed; what did not pass stays as an open PR ("anecdote"). No LLM is used anywhere in verification: verification is deterministic execution. Fixes are typed only (set header, back off N seconds, change param, pin version); no free-text or shell in fixes; URLs only on owner-verified domains. Facts behind third-party authentication or specific to a plan/tenant are not verified by the project and are labeled "reported"; later, operators can opt in to a passive OpenTelemetry exporter that sends metadata of their real calls (never bodies, values or headers) which corroborates such facts. Consumption: an MCP server and HTTP API that answer "explain this error string", "what changed in service S since date D", "is this endpoint failing for others right now"; plus a static page per fact and per error string with llms.txt, so an agent that web-searches an error lands on a dated, verified answer. Service owners can claim their namespace and publish signed official facts (badge "official", not an override of evidence). Goal for the first year: become the single source of truth agents consult before acting on a third-party interface; not revenue. Team: one person plus agents, running ops as automated routines; ~1 hour/week of human time at this stage.
